# 房を選んで髪色をかえるやつ

`com.metlab.ava.haircolor`

髪のメッシュを「房（つながったポリゴンのかたまり）」ごとに見分けて、クリックした房だけ色を変えるエディタ拡張です。
元のメッシュやマテリアルのファイルは書き換えず、複製を作って差し替えます。

## 使い方

1. メニュー `Tools > Metlab > 房を選んで髪色をかえるやつ` を開く
2. 対象の髪のレンダラー（SkinnedMeshRenderer / MeshRenderer）を指定する
3. 「編集開始（プレビュー）」を押す（この時点ではファイルは作られない）
4. 色と塗り方を選び、シーンビューで髪をクリックする。同じ色でもう一度クリックすると解除
5. 「確定して保存」で、複製したメッシュとマテリアルを保存する
6. 「元データに戻す」でいつでも編集前に戻せる

保存したファイルは `Assets/MetlabGenerated/房を選んで髪色をかえるやつ/` に作られます。

## 必要なもの

- Unity 2022.3
- com.vrchat.avatars >=3.7.0
