# アセットのショートカットをつくるやつ

`com.metlab.shortcut`

Project ウィンドウとは別に、自分だけの「仮想フォルダ」でアセットのショートカットを整理できるタブです。
実際のフォルダ構成は変えずに、よく使うものを好きな順番・まとまりで並べられます。

## できること

- 仮想フォルダの作成と、アセット／フォルダのショートカットをドラッグで登録・並べ替え
- クリックで選択、もう一度クリックで開く（フォルダは中に入れる）
- フォルダの色分け、カスタムアイコン、優先度による並び順
- グリッド表示／リスト表示の切り替え
- Project ウィンドウでフォルダを右クリック → `Metlab > フォルダ色` で実フォルダにも色付け

## 使い方

メニュー `Tools > Metlab > アセットのショートカットをつくるやつ` でタブを開き、Project ウィンドウからアセットやフォルダをドラッグして登録します。

データは `ProjectSettings/MET_ShortcutData.json` に保存されます（Assets フォルダは汚しません）。

## 必要なもの

- Unity 2022.3
