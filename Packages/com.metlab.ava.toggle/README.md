# トグルをつくるやつ

`com.metlab.ava.toggle`

アバターの衣装・アクセサリ・小物などを、Expression メニューからON/OFFできるようにするエディタ拡張です。
Modular Avatar の部品を自動で組み立てるので、アバター本体のファイルは書き換えません（非破壊）。

## できること

- カテゴリ（サブメニュー）とアイテム（トグル）の作成。カテゴリ内の排他（どれか1つだけON）
- 初期状態でONにするアイテムの指定
- 「これがONのときは隠す」「全部OFFなら自動で表示」などの条件
- 着用時に素体のブレンドシェイプを変える／消す（服の突き抜け対策）
- コーディネイト（1ボタンで複数のトグルをまとめて切り替え）
- メニューアイコンの設定、パラメータ使用量の確認
- 設定をテンプレートとして保存し、別のアバターで読み込む

## 使い方

1. メニュー `Tools > Metlab > トグルをつくるやつ` を開く
2. 対象のアバターを指定し、「この avatar に衣装トグル設定を作成」を押す
3. 「トグル設定」タブでカテゴリとアイテムを作り、ON/OFFしたいオブジェクトを割り当てる
4. 生成ボタンを押すと、アバター直下に Modular Avatar の部品が作られる

生成物と設定のバックアップは `Assets/MetlabGenerated/トグルをつくるやつ/` に保存されます。

## 必要なもの

- Unity 2022.3
- com.vrchat.avatars >=3.7.0
- nadena.dev.modular-avatar >=1.10.0
